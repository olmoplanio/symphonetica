Font Collection Overview

The Symphonetica system includes four specialized fonts, each crafted for precision and typographic elegance in scholarly work. All fonts are available in TrueType (TTF), OpenType (OTF), and WOFF2 formats.

These fonts are distributed under the SIL Open Font License (OFL), allowing free use, modification, and redistribution for both academic and commercial purposes with attribution.

The code under version control can be found on GitHub.

Installation Instructions

Windows

  1. Download the desired font files (TTF, OTF, or WOFF2)
  2. Right-click on the font file and select "Install" or "Install for all users"
  3. The font will be available in all applications

macOS

  1. Download the desired font files
  2. Double-click the font file to open Font Book
  3. Click "Install Font" in the preview window
  4. The font will be available system-wide

Linux

  1. Download the font files
  2. Copy fonts to ~/.fonts/ or ~/.local/share/fonts/
  3. Run fc-cache -f -v to refresh the font cache
  4. Fonts will be available in applications

Usage Guidelines

Academic Publications

  • Use Laudosia Regular for main body text and phonetic transcriptions
  • Use Laudosia Literal for quotations from classical sources
  • Combine fonts harmoniously for multilingual scholarly work

Digital Publications

  • Fonts are optimized for both print and screen display
  • Web fonts (WOFF2) are available for online publications
  • Unicode compliance ensures cross-platform compatibility
